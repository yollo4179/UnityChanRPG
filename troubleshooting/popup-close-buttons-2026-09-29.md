# 팝업 X 닫기 버튼 (2026-09-29)

## 확인

인벤토리와 장비 팝업에는 이미 `Close_Button`과 닫기 로직이 있었지만 버튼 자식 텍스트가 `Button`으로 남아 있었다. 퀘스트와 스킬 팝업에는 닫기 버튼이 없었다.

## 수정

- 인벤토리와 장비의 기존 버튼 글자를 `X`로 바꾸고 가독성을 높였다. 기존 닫기 콜백을 유지해 인벤토리의 선택 아이템 정리도 그대로 실행된다.
- 퀘스트와 스킬 팝업 오른쪽 위에 `Close_Button`을 추가했다. `UI_ClosePopupButton`이 버튼 클릭을 해당 `UI_Popup.ClosePopUpUI()`에 연결한다.
- 새 버튼은 팝업 패널의 마지막 자식으로 배치해 다른 UI 위에 표시하고, X 텍스트는 레이캐스트를 받지 않도록 했다.

## 검증

네 프리팹에서 버튼 수, X 텍스트, 새 버튼의 부모·자식 연결, 클릭 컴포넌트 연결을 검사했다. 새 스크립트를 포함한 임시 검증 프로젝트의 C# 빌드는 오류 0개로 통과했다. 에디터에서 재컴파일 후 네 팝업을 직접 열고 X 클릭 동작을 확인해야 한다.
